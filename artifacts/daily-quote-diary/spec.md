# 하루한줄 — 감정 동반자 일기

## 개요

하루를 세 타임슬롯(아침·오후·저녁)으로 나눠 시간대에 맞는 한국어 명언과 배경 이미지를 보여주고,
사용자가 짧은 일기를 쓰면 AI가 따뜻한 친구 톤으로 답글을 달아주는 감정 동반자 앱.
과거 일기는 히스토리 페이지에서 목록으로 돌아볼 수 있다.

---

## 범위

### 포함

- 타임슬롯별(아침/오후/저녁) 한국어 명언 + Unsplash 배경 이미지
- 타임슬롯당 1회 일기 입력 (150자 이내)
- 일기 제출 시 AI 감정 분석 + 따뜻한 친구 톤 답글 (2–3문장)
- 일기 수정 가능 (삭제 불가) — 수정 시 AI 답글 재생성
- 히스토리 페이지: 날짜·타임슬롯별 과거 일기 목록
- 로컬 스토리지 저장 (로그인 없음)
- 새벽(00–05시) 접속 시 안내 문구 표시

### 제외

- 감정 달력/통계 시각화 — 히스토리가 쌓인 뒤 2단계에서 구현
- 알림 푸시 — MVP 단계에서 자발적 접근이 더 중요
- 소셜/공유 기능 — 감정 공유는 개인 안전 이슈, 핵심 가치와 거리 있음
- 사용자 계정/로그인 — 로컬 스토리지로 충분히 검증 가능
- 일기 삭제 — 감정 기록의 진정성 보존

## 시나리오

### 1. 아침 타임슬롯 — 명언과 배경 표시

- **Given** 현재 시각이 06:00–11:59 사이이고, 오늘 아침 타임슬롯에 작성된 일기가 없다
- **When** 사용자가 메인 페이지에 접속한다
- **Then**
  - 아침 분위기의 배경 이미지가 화면 전체에 표시된다
  - 희망·동기 테마의 한국어 명언과 출처(인물/출처명)가 명언 카드에 표시된다
  - 일기 입력 필드와 "오늘 어떤 하루인가요?" 안내 문구가 표시된다

성공 기준:
- [ ] 06:00–11:59 접속 → 명언 카드에 한국어 명언 텍스트가 표시된다
- [ ] 06:00–11:59 접속 → 배경 이미지가 화면에 렌더된다
- [ ] 06:00–11:59 접속 → 일기 입력 필드가 표시된다

---

### 2. 일기 작성 → AI 답글 수신

- **Given** 메인 페이지에 일기 입력 필드가 표시되어 있다
- **When** 사용자가 일기 텍스트(1자 이상, 150자 이하)를 입력하고 "기록하기" 버튼을 누른다
- **Then**
  - 버튼이 로딩 상태로 전환되고 입력 필드가 비활성화된다
  - 처리 완료 후 입력한 일기 텍스트와 AI 답글(2–3문장, 따뜻한 친구 톤)이 나란히 표시된다
  - 입력 필드와 "기록하기" 버튼이 사라지고 "수정하기" 버튼이 나타난다
  - 해당 일기와 답글은 페이지를 새로고침해도 유지된다

성공 기준:
- [ ] 일기 입력 후 "기록하기" 클릭 → 로딩 인디케이터가 나타난다
- [ ] 처리 완료 → 화면에 일기 텍스트와 AI 답글 텍스트가 모두 표시된다
- [ ] 처리 완료 → "기록하기" 버튼이 사라지고 "수정하기" 버튼이 나타난다
- [ ] 페이지 새로고침 → 이전에 작성한 일기와 AI 답글이 그대로 표시된다

---

### 3. 같은 타임슬롯 재접속 — 기존 일기 표시

- **Given** 오늘 오후 타임슬롯(12:00–17:59)에 이미 일기를 작성했다
- **When** 오후 타임슬롯 중에 메인 페이지에 다시 접속한다
- **Then**
  - 명언·배경은 처음 접속 때와 동일하게 표시된다
  - 기존 일기 텍스트와 AI 답글이 바로 표시된다
  - 새 일기 입력 필드는 표시되지 않는다
  - "수정하기" 버튼이 표시된다

성공 기준:
- [ ] 재접속 → 일기 입력 필드가 보이지 않는다
- [ ] 재접속 → 이미 작성한 일기 텍스트와 AI 답글이 표시된다
- [ ] 재접속 → "수정하기" 버튼이 표시된다

---

### 4. 일기 수정 → AI 답글 재생성

- **Given** 오늘 타임슬롯에 이미 작성된 일기와 AI 답글이 표시되어 있다
- **When** 사용자가 "수정하기" 버튼을 누르고 내용을 변경한 뒤 "저장하기" 버튼을 누른다
- **Then**
  - 수정된 일기 텍스트가 화면에 표시된다
  - 이전 AI 답글이 사라지고 새 AI 답글(수정된 내용 기반)이 생성되어 표시된다
  - "수정하기" 버튼이 다시 표시된다

성공 기준:
- [ ] "수정하기" 클릭 → 일기 텍스트가 편집 가능한 상태로 전환된다
- [ ] 수정 저장 → 화면에 새로운 일기 텍스트와 새 AI 답글이 표시된다
- [ ] 수정 취소 → 원래 일기와 AI 답글이 그대로 유지된다

---

### 5. 히스토리 페이지 — 과거 일기 목록

- **Given** 로컬 스토리지에 최소 1개 이상의 일기가 저장되어 있다
- **When** 사용자가 히스토리 페이지로 이동한다
- **Then**
  - 날짜 내림차순으로 일기 목록이 표시된다
  - 각 항목에 날짜, 타임슬롯 이름(아침/오후/저녁), 일기 텍스트 앞부분(최대 50자), AI 답글 앞부분(최대 50자)이 표시된다
  - 저장된 일기가 없으면 "아직 기록이 없어요" 메시지가 표시된다

성공 기준:
- [ ] 히스토리 페이지 접속 → 저장된 일기 수만큼 목록 항목이 표시된다
- [ ] 각 항목 → 날짜와 타임슬롯 이름이 보인다
- [ ] 일기가 없을 때 → "아직 기록이 없어요" 문구가 표시된다

---

### 6. 150자 초과 입력 시도

- **Given** 일기 입력 필드가 표시되어 있다
- **When** 사용자가 151자 이상을 입력하려 한다
- **Then**
  - 150자를 초과하는 글자는 입력되지 않는다
  - 현재 입력 글자 수 / 150 형식의 카운터가 표시된다

성공 기준:
- [ ] 151번째 글자 입력 시도 → 입력 필드의 텍스트가 150자를 넘지 않는다
- [ ] 텍스트 입력 중 → "현재글자수/150" 형식의 카운터가 표시된다

---

### 7. 새벽(00–05시) 접속

- **Given** 현재 시각이 00:00–05:59 사이이다
- **When** 사용자가 메인 페이지에 접속한다
- **Then**
  - 명언 카드나 일기 입력 필드 대신 "06:00에 다시 오세요 🌅" 안내 문구가 표시된다
  - 히스토리 페이지로 이동하는 링크는 표시된다

성공 기준:
- [ ] 00:00–05:59 접속 → 일기 입력 필드가 표시되지 않는다
- [ ] 00:00–05:59 접속 → 안내 문구가 화면에 표시된다

## 불변 규칙

**데이터 지속성**
로컬 스토리지에 저장된 일기와 AI 답글은 페이지 새로고침·탭 닫기 후 재접속해도 유지된다.

**타임슬롯 격리**
아침·오후·저녁 타임슬롯은 서로 독립적이다. 아침에 일기를 썼어도 오후 타임슬롯이 되면 새 일기 입력 필드가 표시된다.

**AI 답글 톤**
모든 타임슬롯에서 AI 답글은 판단·조언 없이 감정 공감 중심으로, 2–3문장을 넘지 않는다.
