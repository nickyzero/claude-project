# 하루한줄 — 감정 동반자 일기

## Problem Statement
HMW — 아침부터 저녁까지 혼자 감정을 삭히는 사람들이,
판단 없이 공감해주는 동반자와 함께 하루를 열고 닫게 할 수 있을까?

## Recommended Direction
시간대(아침/오후)별 명언 + 배경으로 하루를 감정적으로 "프레이밍"한 뒤,
짧은 일기를 쓰면 Gemini가 따뜻한 친구 톤으로 답글을 달아주는 구조.
감정 달력은 2단계 — MVP는 오늘 하루의 루프에만 집중.

핵심 루프: 명언 보기 → 짧은 일기 → AI 답글 받기

## Key Assumptions to Validate
- [ ] AI 답글이 실제로 따뜻하게 느껴진다
      → 5명에게 테스트 후 "다시 쓰고 싶다" 반응 확인
- [ ] 사용자가 짧게라도 매일 쓰는 루틴이 형성된다
      → 1주 리텐션으로 측정
- [ ] 아침/오후 명언 구분이 의미 있다
      → 시간대 고정 vs 선택 A/B

## MVP Scope
포함:
  - 아침(06–11시) / 오후(12–18시) 시간대 자동 감지
  - 시간대별 명언 (Gemini 생성, 한국어) + 배경 이미지
  - 일기 입력 (150자 이내)
  - Gemini API 감정 분석 + 한 문단 따뜻한 답글
  - 로컬 스토리지 저장 (로그인 없음)

미포함:
  - 감정 달력/통계 (2단계)
  - 알림 푸시
  - 소셜/공유
  - 사용자 계정

## Not Doing (and Why)
- 외부 명언 API — ZenQuotes 영어 전용, 한국어 톤 조절 불가
- 알림 푸시 — MVP 단계에서 습관 강제보다 자발적 접근이 더 중요
- 소셜 기능 — 감정 공유는 개인 안전 이슈, 핵심 가치와 거리 있음
