상태 A — 아침 · 일기 미작성
  • 전체 화면 배경 이미지 위에 반투명 오버레이
  • 타임슬롯 배지: 아침/오후/저녁에 따라 아이콘·색 변경
  • textarea 최대 150자, 실시간 카운터 표시
  • "기록하기" 클릭 → 로딩 상태 → 상태 B로 전환
상태 B — 작성 완료
  • 일기 텍스트와 AI 답글이 하나의 카드 안에 나란히 표시
  • AI 답글: 2–3문장, 따뜻한 친구 톤, 판단·조언 없음
  • "수정하기" 클릭 → 상태 C로 전환
  • 새로고침 후 재접속해도 이 상태 유지 (로컬 스토리지)
상태 C — 수정 중
  • 기존 AI 답글은 숨겨지고 입력 필드가 편집 가능 상태로 전환
  • "저장하기" → AI 답글 재생성 후 상태 B로 복귀
  • "취소" → 변경사항 무효, 상태 B로 복귀
  • 저장 알림 문구: "저장하면 AI 답글이 다시 생성됩니다."
상태 D — 새벽 (00–05시)
  • 명언·일기 입력 없이 안내 화면만 표시
  • "지난 기록 보기" → 히스토리 페이지로 이동
  • 06:00이 되면 자동으로 상태 A로 전환 (타이머 또는 새로고침)
상태 E — 히스토리 목록
  • 날짜 내림차순, 날짜 그룹 헤더로 묶음

  • "← 돌아가기" → 메인 페이지로 이동
